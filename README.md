# 🔐 Password Generator

A simple command-line password generator written in Python, as my first project.

## Features

- Generate one or multiple passwords
- Choose password length
- Enable or disable:
  - Lowercase letters
  - Uppercase letters
  - Numbers
  - Symbols
- Password history
- Persistent history using JSON

## Technologies

- Python 3
- JSON
- File Handling

## Future Improvements
